# Item icons (Codex) — 50 icons in 5 sheets

Style: same pixel-art look as the ability icons in `art/raw/icons/*.png` (crisp hard pixels, black outline, bright readable colors, no anti-aliasing/blur). Setting: a tech / hacker / office / gym / military / fantasy-tech MOBA.
Each icon is ONE object, centered in its cell, filling ~80% of the cell, slightly 3/4 view, with a strong silhouette. NO background (the game paints a gray/green/blue/purple/red square behind it), NO text, NO borders, NO grid lines.

## Sheet format (strict — a script slices them)
- Each sheet: `art/raw/items/sheet_N.png`, exactly 1280 x 512 px: a grid of 5 columns x 2 rows, every cell exactly 256 x 256.
- Flat PURE MAGENTA #FF00FF background everywhere (including between icons). No other magenta in the icons.
- Order is row-major: cell 1 = top-left ... cell 5 = top-right, cell 6 = bottom-left ... cell 10 = bottom-right.
