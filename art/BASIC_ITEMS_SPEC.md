# Basic (craftable component) item icons (Codex) — 1 sheet, 12 icons, SMALL (no HD needed)

Same pixel-art style as the other item icons (crisp hard pixels, black outline, bright readable colors, no anti-aliasing). Tech / hacker / gym / office MOBA. Each icon is ONE simple object, centered, ~75% of its cell, strong silhouette, simpler than the existing item icons (these are the "ingredients"). NO text, NO borders, NO background square.

## Sheet format (strict — a script slices it)
`art/raw/items/basics.png`, exactly 512 x 384 px: grid of 4 columns x 3 rows, every cell exactly 128 x 128, row-major. Flat PURE MAGENTA #FF00FF background everywhere, no other magenta in the icons.
